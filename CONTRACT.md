# Chartroom Studio 1.3 — module contract

This repository is the canonical working source. Runtime code lives in **src/** modules; offline distributions are generated from this source. Make future changes here and keep private lecture projects outside the repository.

- `src/parser.js`: CommonJS export / `ChartroomParser`: `parse(text)`, `rules`, `cleanInline(text)`, `safeAssetPath(path)`.
- `parse` returns `{version:1,title,slides,assets:[relativePaths],diagnostics:[{severity,code,line,message}]}`. Line numbers are 1-based. Errors block export. Slide shape: `{kind,title,line,eyebrow,hue,reveal,items:[{text,line,children}],body:[],columns:[{title,items}],footer,notes:[],image,alt,credit,attribution,meters:[{label,value}],spectrum:null|{left,right},portraits:[{image,name,credit,alt}],citation,takeaway,polarity}`. Defaults are empty strings/arrays and false, except `spectrum:null`; no missing content fields. Kinds: cover/divider/part/facts/cards/two-col/quote/big/photo/somber/img/lens/duo/scholar.
- `src/renderer.js`: CommonJS / `ChartroomRenderer`: `renderDeck(model,{mode:'teaching'|'review',assetUrls:{path:url},deckId,palette:'classic'|'buster'|'agnar'|'atlantic'|'field-notes'|'aubergine'|'night-seminar'})` and `renderLibrary({title,code,palette,lectures:[{id,title,model:null|model}]},{assetUrls:{lectureId:{path:url}}})` return complete readable HTML. No source model/private notes embedded. Default image references remain relative. Sandboxed review iframes use srcdoc. `styles` exposes the deck CSS.
- Generated player exposes `ChartroomPlayer.next/previous/home/end/go/getState/audit`. State `{index,step,count}`. Messages use `chartroom-command` and `chartroom-state`, validating source and origin, with a deliberate opaque/local-origin exception.
- `src/package.js`: CommonJS / `ChartroomPackage`: `validateProject`, `compile`, `build`, `zip`, `safePath`, `decodeBase64`, `imageMime`, `crc32`. `compile(project)` returns `{lectures,diagnostics}`; `build(project,'student'|'teaching')` returns `{files:[{path,data}],diagnostics}`. ZIP data is UTF-8 text or Uint8Array. Student ZIP contains index.html, referenced images, README.txt; teaching ZIP contains lectures/<id>/index.html and relative images.
- Project: `{format:'chartroom-studio',version:1,course:{title,code,palette},lectures:[{id,title,notes,available:boolean}],assets:[{lectureId,path,mime,data:base64}]}`. Palette is a named ID (`classic`, `buster`, `agnar`, `atlantic`, `field-notes`, `aubergine`, `night-seminar`), normalized to `classic` when absent. Renderer exposes frozen `palettes` and strict `paletteId`. Palette is passed to previews, library, teaching exports and preflight. Project is PRIVATE source; exports are public snapshots. IDs are lowercase safe slugs. Asset names are safe relative raster paths.
- `src/preflight.js`: browser-only `ChartroomPreflight.check(project)` returns an async diagnostics array after rendering each available lecture, decoding images, and checking all slides for overflow. The GUI gates exports on this check. CLI has no browser and does not claim visual validation.
- `src/presenter.js` + `src/presenter.css`: browser-only `ChartroomPresenter.open(project,lectureId,onError)`. Presents a validated selected-lecture snapshot in teaching mode after real preflight, with local embedded images and no private source in its scripts-only sandbox. Synchronously hides/inerts the editor; native fullscreen has a page-fill fallback. Escape/native exit/button share cleanup and restore focus/inert state. The generated presentation-only Tab bridge does not change exports. Error details are reported to the private Studio notice, not the projected screen. No project-schema change.
- `src/app.js` + `src/studio.css`: browser workshop controller and shell for local-file or static-hosted use. `index.html` loads classic same-folder scripts. The hosted app loads its files over the network; project processing and autosave remain in the browser, without cloud sync or automatic publishing. The offline download link is shown only under HTTP(S). There is no service worker or guaranteed offline reload of the hosted app.

## Per-slide spectrum labels

`@spectrum Left label | Right label` is an authored, per-slide directive on its own line. The parser and renderer must preserve both endpoint labels for the slide’s `@lens` axis and any `@slider`, `@slider1`, or `@slider2` meters. Without it, Closed/Open remains the default. It does not alter numeric values, individual meter names, palette colors, or neighboring slides, and does not create an axis or meter by itself. No course-wide/global setting or label inheritance is introduced. **Insert an element or tool** exposes spectrum labels through the annotation insertion path. Explicit private text must not leak through endpoint labels into public output.

## Browser draft conversion

`src/converter.js` exports `ChartroomConverter` in the browser and CommonJS: synchronous `fromText(text,{title})` and `fromHTML(html,{title})`, asynchronous `fromPptx(arrayBuffer,{title})` and `fromFile(file,{title})`, plus `limits`. Results are `{title,notes,warnings}`. HTML/PPTX require browser XML/HTML parsing; compressed PPTX uses the browser's native decompression support. The app routes selected files through `fromFile`, including strict UTF-8 validation. Limits include 32 MiB PPTX input and 2 MiB text/HTML input, with separate archive-expansion, structure, slide-count and output bounds. Invalid inputs produce actionable errors without replacing the current draft.

- Entry: sidebar **Convert text / slideshow**; modal **Convert to draft notes**. Inputs are pasted text or one `.txt`, `.md`, `.pptx`, `.html`, or `.htm` file, with an optional title. Google Slides/Keynote presentations are supported through `.pptx` export only; older `.ppt` and PDF are unsupported, with guidance to export `.pptx` or paste text.
- Output: editable annotated draft notes, not a finished reconstruction. Headings, list hierarchy, and slide boundaries are approximate; source wording is not rewritten. Images, charts, animations, and slide layout are not imported.
- Actions: **Save draft .md** downloads the edited annotated source, which may contain private notes. **Add as new draft lecture** creates a separate lecture with `available:false` (**Coming soon**). It must not overwrite the current lecture. Unavailable content stays out of public exports; its library label may still appear. No project-schema change is needed.
- Privacy: PPTX speaker notes stay private; explicit source private annotations are protected. Ambiguous Chartroom syntax may be placed in private notes with a cleanup warning. Raw text and HTML require author review; the converter must not promise to infer secret prose. Imported HTML is data to extract, not executable content.
- Processing: browser-local, no uploads or remote conversion service, and usable in the extracted offline app. Hosted offline-reload limitations remain unchanged.
- Separation: existing **Import .md / .txt notes** is the exact-annotations path. The Python converter for supported older Chartroom HTML remains a separate fidelity-oriented legacy tool, including its known-layout and local-image support.

The normative rules and supported annotation grammar are in docs/RULES.md and docs/ANNOTATIONS.md. Existing lectures are never overwritten; notes are the authoring source of truth. Run unit, browser, hosted-mode, and extracted-archive checks before release. See VERIFICATION.md for actual status, results, and limitations.
