Open Studio

If you are using a hosted copy, choose Open Studio above. To work locally, download Chartroom-Studio-Offline.zip, extract the entire archive, and open index.html or this page in a modern desktop browser. Keep the extracted folder together; do not open HTML files inside an archive viewer. You do not need Node.js, Python, Hermes, or a terminal to use the app.

The local copy works without an Internet connection. A hosted page needs a connection to load again: Studio has no service worker or guaranteed offline cache. Use the hosted app's Download offline Studio link before you need to work without a connection.

Make a lecture

  1. Choose Open demonstration, New blank project, or Open project. Save your current project before replacing it.
  2. Write annotated notes or import .md / .txt files. Add your images under Local images; their listed paths must match the notes exactly.
  3. Choose teaching or review preview. Follow diagnostics to their source lines. Studio checks images and slide overflow before export; split a crowded slide in the notes.
  4. Save project keeps your editable notes and images. Export a teaching or student ZIP and extract it before opening. Share the student export, not your private project.

Write annotated notes

# Your lecture title

## Your main point
- Your exact words.
  - A dependent detail.
- Your next point.

*This explanation stays in your private notes.*

## A question for the class? @big

One # cover comes first; each ## starts a slide. This is a restricted annotation language, not all of Markdown. **Bold words** are visible. Single-star asides, %%private spans%%, @notes lines, and HTML comments stay private. Plain text is public, including answers left unmarked.

Insert slide adds complete layouts, including cards, columns, quotations, image exhibits, paired portraits, scholar citations, and the closed/open axis. Insert an element or tool adds individual annotations below the current line; Bold can wrap selected words. Replace the highlighted sample text. See the complete annotation reference.

Choose a palette

Deck palette offers Chartroom Classic, Buster, Agnar, Atlantic, Field Notes, Aubergine, and Night Seminar. The choice applies to every lecture and the student review page and is saved in your project. Projects without a palette use Classic. Compare the editorial palettes; check image contrast and Night Seminar on the classroom display. Export again to update an older shared deck.

Present without exporting

Select a lecture and choose Present lecture. Studio checks it, then opens a fixed teaching-mode snapshot at the first slide. The editor and private notes are hidden. Fullscreen is requested; if the browser refuses it, the deck fills the page.

  • Right arrow, Space, or Page Down advances a reveal, then a slide.
  • Left arrow or Page Up goes backward. Home and End jump to the endpoints.
  • Press Tab or move to the upper-right corner to expose the help/exit strip.
  • Escape or Exit presentation returns to Studio.

Exiting exposes the private editor again. Blank the projector or stop screen sharing before leaving presentation mode if your notes must remain unseen. There is no separate private presenter window.

Choose the right file to share

  • Save project downloads a private .chartroom.json file with all source notes, private asides, course settings, and embedded images. Reopen it with Open project.
  • Save .md downloads the selected lecture's source, including private notes. It does not include image files or the whole project.
  • Teaching decks .zip contains public slides and referenced images. Facts reveal a parent point and its children together.
  • Student library .zip contains public review slides and course navigation. All points are visible; selecting a lecture starts at its first slide. Students have Previous/Next, a counter, a mobile lecture menu, and fullscreen.

Public exports omit private annotations and the source project. Unavailable lectures contribute only their library labels. Check visible text and images before sharing; only explicitly marked notes are private. Exports are snapshots, not synced copies. Updating notes does not change an older download or a published course site.

Keep a project backup

Studio processes projects in your browser. It has no cloud sync or project-upload service. Autosave uses browser localStorage, which is neither encrypted storage nor a backup. Other people using the same browser profile may be able to read it. Clearing site data, storage limits, or private browsing can remove drafts.

Use Save project regularly and keep personal projects outside the source repository. Autosave belongs to a browser profile and origin; local-file storage also depends on the browser and file location. To move from an old folder to a new copy or a hosted site, use Save project in the old app and Open project in the new one.
